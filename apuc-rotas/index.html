INTEGRAÇÃO

Google Maps

A leitura do texto da fotografia é feita por OCR. Para transformar Rua + número em coordenadas, o aplicativo consulta o Google Maps. Informe uma chave com a Maps JavaScript API habilitada. A chave fica salva somente neste navegador. Sem a chave, continuam disponíveis a leitura de coordenadas numéricas e o GPS/EXIF.

Ordem de localização: coordenadas escritas no canto inferior direito → Rua + número no canto inferior esquerdo + Google Maps (Apucarana/PR) → mini mapa → GPS/EXIF. Quando o endereço é reconhecido, o sistema salva também o endereço retornado pelo Google Maps para conferência.
Salvamento na nuvem — Google Drive

O aplicativo pode manter uma cópia completa dos dados no seu Google Drive. O backup inclui rotas, fotos, sinistros, laudos, unidades das planilhas e configurações. O acesso é feito pelo login Google no próprio navegador.
